# 우리 아기 동화책

아기 사진과 이름을 넣으면 아기가 주인공인 그림 동화를 만들어 주는 휴대폰용 웹앱이에요.
AI를 쓰지 않아서 **토큰 비용이 0원**이고, 사진은 **기기 밖으로 나가지 않아요.**

## 어떻게 동작하나요

- **이야기**: 미리 써 둔 장면 조각을 조합해요. 한 권은 11쪽(표지 → 시작 → 친구 등장 → 출발 → 놀이 2개 → 문제 → 해결 → 선물 → 집으로 → 마지막 인사)이고, 쪽마다 후보 장면 중 하나를 고르기 때문에 같은 장소·친구여도 수십만 가지 이야기가 나와요.
- **이름**: 받침에 맞춰 조사를 붙여요. `민준` → "민준이가", "민준아" / `지우` → "지우가", "지우야".
- **그림**: 배경은 SVG 도형으로 그리고, 동물·소품은 이모지로 올려요. 아기 몸은 그림이고 얼굴 자리에 고른 사진을 동그랗게 넣어요.
- **같은 이야기 다시 보기**: 이야기마다 번호(seed)가 있어서, 책장에 꽂아 두면 언제든 똑같은 이야기를 다시 펼칠 수 있어요.
- **읽어 주기**: 기기에 들어 있는 음성(Web Speech API)으로 읽어 주고, 다 읽으면 다음 쪽으로 넘어가요.
- **오프라인 / 앱 설치**: 한 번 열면 인터넷 없이도 열려요. 휴대폰에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 실행하기

빌드 과정이 없는 정적 파일이에요.

```bash
npx serve fairytale        # 또는 아무 정적 서버
```

`fairytale/index.html`을 브라우저로 바로 열어도 동작해요. 오프라인 기능만 빠져요.
GitHub Pages로 저장소를 배포하면 `https://<계정>.github.io/<저장소>/fairytale/` 주소로 열려요.

## 테스트

```bash
node --test "fairytale/tests/*.test.js"
```

모든 장소 × 친구 × 이름 조합에서 빈칸 없이 11쪽이 나오는지, 조사가 맞는지, 같은 번호면 같은 이야기가 나오는지 확인해요.

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `js/stories.js` | 동화 문장과 장면 그림 명세, 이야기 조합기 |
| `js/josa.js` | 받침에 맞춘 조사 붙이기 |
| `js/art.js` | 장면 명세를 SVG 그림으로 그리기 |
| `js/photo.js` | 사진에서 얼굴 부분 동그랗게 자르기 |
| `js/app.js` | 화면 전환, 저장(책장), 읽어 주기 |
| `sw.js`, `manifest.webmanifest` | 오프라인 보관과 홈 화면 설치 |

## 이야기 늘리기

`js/stories.js`의 `WORLDS`에서 장소를 고르고 `trips`(놀이), `troubles`(문제와 해결), `gifts`(선물) 배열에 장면을 추가하면 돼요.
문장 안에는 `{name:이/가}`, `{call}`, `{f:은/는}` 같은 자리표시자를 쓰고, 조사는 "받침 있을 때/없을 때" 순서로 적어요.
자리표시자 목록과 그림 명세 형식은 파일 맨 위 설명에 있어요. 새 장면을 넣은 뒤에는 테스트를 돌려 주세요.
